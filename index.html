About This Project

Documenting the AWS learning journey

This portal documents a hands-on journey through AWS cloud services while preparing for the AWS Certified Solutions Architect – Associate (SAA-C03) exam. Every page is written from a practitioner's perspective — not just theory, but real architectural reasoning, trade-offs, and exam-relevant insights.

The goal is to build something useful for the broader community. Rather than keeping notes in a private notebook, sharing everything publicly makes the knowledge accessible to anyone studying for AWS certifications.

This is a living project. Content is added continuously as each AWS service is studied, documented and validated. Contributions, suggestions and feedback are always welcome.

✓
Built for real learners Written in plain language with practical examples, not marketing copy.
✓
Exam-focused content Every service page highlights what actually matters for the SAA-C03 exam.
✓
Continuously updated New content is added as each service is studied and documented in depth.
✓
Always free All study notes, cheat sheets, and resources are free to access and share.
